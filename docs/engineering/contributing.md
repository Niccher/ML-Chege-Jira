# Contributing Guidelines

Thank you for contributing to **ML Chege Jira**. Follow these guidelines to maintain high codebase and documentation standards.

## Development Workflow

1. Fork or branch from `main` using descriptive branch names (`feat/sprint-insights`, `fix/task-stream-timeout`).
2. Implement your feature or bugfix adhering to strict typing (`strict = true` in MyPy).
3. Ensure all tests pass: `pytest`.
4. Ensure code formatting is clean: `ruff format app tests`.
5. Update relevant documentation in `docs/`.
6. Submit a pull request referencing the related issue or feature ticket.
